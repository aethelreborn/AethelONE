# Upstream sync: custom game arguments, mods folder sync, and browser links

Game settings has a Game Arguments field for extra Minecraft arguments, globally or per cluster. The Mods list reacts to jars added, renamed, or deleted by hand. GitHub-hosted mods can open their repository in the browser, and fixes cover URL opening, dGPU selection, invisible icons, repeated mclo.gs notifications, the optional-bundles prompt on new versions, the system-info copy tooltip, and icon display on Linux with a comma decimal locale.
