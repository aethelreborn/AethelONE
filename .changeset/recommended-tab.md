# Recommended tab surfaces a curated, cluster-aware mod catalog

The package manager gains a "Recommended" chip listing hand-picked client-side packages (Sodium, Iris, Mod Menu, JEI, EMI, and more), gated to the cluster's loader and Minecraft version. Picks not yet installed offer a one-click Install button that narrows to the cluster's exact compatibility, and every row opens the package page for version picking. Installed picks keep their normal rows, toggles, and delete controls.
